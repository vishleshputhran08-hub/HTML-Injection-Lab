Burp Suite - GET vs POST

GET: In a real GET request, parameters are contained in the URL (e.g. ?firstname=Test&lastname=Jogi). Because the data is visible in the URL, it can be viewed and modified using tools like Burp Suite before the request reaches the server.

POST: A real POST request sends data in the request body and requires a server endpoint to receive and process it. Since this project is intentionally static and contains only index.html, there is no server-side POST endpoint, so the POST experiment is simulated locally in the browser.
